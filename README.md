# NOCTURNE

Запуск локально из этой папки

```powershell
node server.mjs
```

Открой http://127.0.0.1:8787/. Этот процесс поднимает сайт и музыкальный API. Если сайт открыт через Live Server на порту 5500, API всё равно должен работать на 8787.

- `src/` — страницы, главная, навигация и клиент Firebase.
- `src/styles/` — базовые компоненты и оформление витрины.
- `server/music-sources.mjs` — музыкальные источники, региональные чарты и кэш запросов.
- `assets/` — оформление.
- `firestore.rules` — правила Cloud Firestore.

Главная загружает живые данные. Гости просматривают внешние релизы. После входа релиз синхронизируется с Firestore при открытии, чтобы сохранить оценки и рецензии.

Чарты России и США загружаются из Apple Music. Поиск сначала обращается к Deezer, а дополнительные результаты доступны из Apple, MusicBrainz и Audius. Обложки MusicBrainz загружаются из Cover Art Archive.
